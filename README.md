# 📝 Todo List (Flask)

## 📌 Описание проекта
Данный проект представляет собой веб-приложение для управления списком задач (Todo List), разработанное на языке Python с использованием фреймворка Flask.

Пользователь может добавлять, просматривать и удалять задачи через удобный веб-интерфейс.

---

## 🎯 Цель работы
Создание простого веб-приложения с использованием Python и Flask, закрепление навыков работы с серверной логикой и обработкой пользовательских данных.

---

## ⚙️ Функционал
- ➕ Добавление новых задач  
- 📋 Просмотр списка задач  
- ❌ Удаление задач  
- 💾 Сохранение данных в файл (JSON)

---

## 🛠️ Используемые технологии
- Python  
- Flask  
- HTML / CSS  
- JSON (для хранения данных)

---

## 🚀 Запуск проекта

1. Установить зависимости:
pip install -r requirements.txt

2. Запустить приложение:
python app.py

3. Открыть в браузере:
http://127.0.0.1:10000
